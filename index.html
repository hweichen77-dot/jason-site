Things I've shipped.

Each one is live or open source. Click through.

  • Compilearn

    React, Vite, Tailwind, Tauri, Supabase, Groq

    A free, open-source platform that teaches programming through four tracks, from AP CSP to competitive C++, with an AI playground where you defend a model against adversarial prompts. It grew out of three months of tutoring kids who had no other way in.

    open source ↗

  • Square Analytics for Walley's

    TypeScript, Rust

    The desktop app a 9-person team opens every day to audit 8,654 transactions and $45,922 in sales. It flags Square POS errors nobody used to catch and cut inventory discrepancies by 42%.

    deployed ↗

  • DECA Form Checker

    Python, Tesseract OCR

    Reads the ~600 signed PDFs the chapter collects each year and sorts them into correct, incorrect, and needs a look. It only passes a form on positive evidence, because an unsigned medical release is worse than a false reject. Replaced 10+ hours of eyeballing per cycle.

    deployed ↗

  • Event Scheduler

    Go, Python, Protocol Buffers

    Turns a registration spreadsheet into a full mock-conference schedule, assigning students to events, judges by expertise, and rooms without back-to-back collisions. Validated on a real run of 279 students and 43 judges.

    open source ↗

  • HomeFit

    Rust, Tauri, React, TypeScript

    A free desktop app that pulls live HUD housing data and lets someone filter subsidized listings by location and income on a map. Built on the idea that finding affordable housing shouldn't require a spreadsheet habit.

    open source ↗

  • Tape

    JavaScript, Tauri

    A day-trading game on a market that doesn't exist. Every price is a pure function of a seed and a minute, so 6,200 symbols build in 50 ms and nothing is stored. Twenty sessions, $10k, roguelike perks, and a ghost curve of your best run. Built for fun.

    open source ↗

  • Roommate and Mentor Matching

    Python, pandas, C++

    A C++ checker that cross-references every conference registration against the official roster before matching runs, plus the pairing algorithm that sorts students into rooms of four. Saves about four days of data cleaning per conference.

    deployed ↗

Independent software engineer.

2025 to present. No client, no boss, no ticket queue. I find something that's done by hand, badly, and build the thing that does it instead.

That's how every project above started. The store needed to see its own numbers, so I built the analytics app. The chapter was eyeballing 600 PDFs, so I built the checker. Twenty kids in a WeChat group wanted to learn Java, so I wrote the course and then built Compilearn so it could outlast me.

Along the way that's meant shipping cross-platform desktop apps in Tauri, writing Rust for the parts that need to be fast, running OCR pipelines on phone photos, building constraint solvers in Go, and keeping four open-source repos maintained with real users on the other end.
